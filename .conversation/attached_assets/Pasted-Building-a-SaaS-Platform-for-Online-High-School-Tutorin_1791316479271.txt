Building a SaaS Platform for Online High School Tutoring ()
Summary
build a complete online tutoring SaaS platform TheTutorGuru using your specified stack: .NET, Minimal API, MudBlazor, Dapper, ASP.NET Core Identity, and PayGate/Peach Payments. The core features map cleanly: subject selection + subscription (R290/month single subject, R495/month two subjects), payment processing, live classes, recorded playback, notes upload, and three user roles (Parent, Learner, Tutor). The biggest technical risk is live streaming — for an MVP, integrate Microsoft Teams or Zoom rather than building your own streaming infrastructure.

3. Payment Integration (PayGate / Peach Payments)
TeachMe2 uses PayFast for recurring monthly billing. If your target market is South Africa, PayGate or Peach Payments are the logical choices.
3.1 Peach Payments API Essentials
Peach Payments offers a Server-to-Server API and a hosted payment page (COPYandPAY). For subscriptions:
1.	Auth: Use clientId, clientSecret, and merchantId to obtain an access token
2.	Create Checkout: POST to /v1/checkouts with the payment request
3.	Webhook: Payment result is encrypted and pushed to your callback URL — you must decrypt and verify
3.2 Subscription Lifecycle
•	Create: Parent selects subject → Subscription record created → first payment initiated
•	Auto-renew: PayGate/Peach supports recurring payment configuration
•	Cancel: Service continues until the end of the current billing cycle
•	Refund: Full refund within 30 days, handled via the PeachRefunds NuGet package
4. Recorded Videos: Capture & Playback
4.1 Live Session Recording
TeachMe2 uses Microsoft Teams for live classes, and recordings appear in the learner dashboard within 24 hours. Two implementation paths:
Option A (recommended for MVP): Integrate Teams/Zoom API, pull the recording file into object storage after the live session ends.
Option B (self-hosted): Use VisioForge Video Capture SDK for .NET, which supports capturing from camera/screen and outputting to MP4, MKV, HLS, RTMP. It supports H.264/H.265/AV1 encoding and hardware acceleration (NVIDIA NVENC, Intel QuickSync).
4.2 Playback: HTTP Range Streaming
Never download the full video file at once. ASP.NET Core has built-in support for HTTP Range requests via enableRangeProcessing: true, letting the player scrub the timeline.
There's a complete .NET 9 video streaming API reference implementation on GitHub supporting SQL Server FileStream backends and configurable chunk sizes. The StreamFlex.AspNetCore NuGet package also provides lightweight range streaming.

7.2 Dapper Repository Example
csharp
public class CourseRepository : ICourseRepository
{
    private readonly IDbConnection _db;
    
    public async Task<IEnumerable<CourseWithTutor>> GetCoursesBySubjectAsync(
        string subject, int grade)
    {
        const string sql = @"
            SELECT c.Id, c.Title, c.Schedule,
                   u.Id AS TutorId, u.FullName AS TutorName
            FROM Courses c
            JOIN AspNetUsers u ON c.TutorId = u.Id
            WHERE c.Subject = @Subject AND c.GradeMin <= @Grade 
                  AND c.GradeMax >= @Grade AND c.IsActive = 1";
        
        return await _db.QueryAsync<CourseWithTutor>(sql, 
            new { Subject = subject, Grade = grade });
    }
    
    // Dapper multi-mapping: get Learner + Course + Tutor in one query
    public async Task<IEnumerable<EnrollmentDetail>> GetLearnerEnrollmentsAsync(
        string learnerId)
    {
        const string sql = @"
            SELECT e.*, c.*, u.FullName AS TutorName
            FROM Enrollments e
            JOIN Courses c ON e.CourseId = c.Id
            JOIN AspNetUsers u ON c.TutorId = u.Id
            WHERE e.LearnerId = @LearnerId AND e.Status = 'Active'";
        
        return await _db.QueryAsync<EnrollmentDetail, Course, Tutor, EnrollmentDetail>(
            sql,
            (enrollment, course, tutor) => {
                enrollment.Course = course;
                enrollment.Course.Tutor = tutor;
                return enrollment;
            },
            new { LearnerId = learnerId },
            splitOn: "Id, TutorId");
    }
}
Dapper's design advantage: the application controls connection creation, which matters when integrating with elastic database client libraries or sharding scenarios.

8.2 Key Risks
Self-hosted live streaming costs more than expected. RTMP/HLS infrastructure requires transcoding, CDN distribution, and concurrency scaling. Use Teams/Zoom integration for the MVP — only consider VisioForge or Mediasoup once the business model is validated.
Verify PayGate's .NET SDK maturity early. Peach Payments has documented Server-to-Server APIs and a refund NuGet package, but PayGate's ecosystem support needs confirmation. If PayGate integration proves difficult, Peach Payments is the safer choice.
Video storage costs add up. A 180-learner class with 2 weekly sessions generates a large volume of video per academic year. Use Azure Blob cool/archive tiers to control costs, and keep only the last 2–3 months in hot storage.
